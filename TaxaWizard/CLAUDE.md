## Current behaviour worth knowing

- `workflow_export_prompts()` generates `llm_prompts/` from the INSTALLED packages; each README's Quick Start is read from the repository root. The pack carries each function's full `\details` and its titled `@section` blocks.
- Always pass `placeholder_setup_report = TRUE` when regenerating for the repository, or the committed placeholder is overwritten with the generating machine's own setup check.
- `inst/TaxaID_Workflow_Template.R` is GENERATED by the builder from `inst/graph/snippets/`, never hand-edited. `tests/testthat/test-pack.R` and `test-workflow-template.R` guard both artefacts, and CI treats a SKIP in either as a failure.

## Conventions

- Native pipe `|>`, never `%>%`.
- `utils::globalVariables()` first line of any file using NSE column names.
- Internal helpers take a `.` prefix and `@noRd`. Put them ABOVE the documented
  function's roxygen block: a helper between a block and its function steals that
  block, which has shipped an exported function unexported before now.
- `dplyr::if_else()`, not `ifelse()`, wherever either branch could be length 1.
- Run `devtools::document()` after any roxygen change, and `devtools::check()` after
  any substantive edit.
