# CLAUDE.md -- TaxaID ecosystem

Ecosystem-level context, auto-loaded from any package subdirectory. Each package has
its own CLAUDE.md with its exported functions and current behaviour.

## Development history

The narrative history of this project -- session notes, past decisions, the reasoning
behind them, and the full footgun catalogue -- lives in the TaxaID_dev repository under
`ecosystem_docs/session_notes/`, with the ecosystem-level narrative at
`ecosystem_CLAUDE_2026-10.md` and one `<pkg>_CLAUDE_2026-10.md` per package. This file
carries current state only. Read the archive when you need to know WHY something is the
way it is; read this file to know what is true now.

## The nine packages

| Package | Purpose |
|---|---|
| TaxaTools | Name verification, cleaning, parsing, rank lookup; the LLM provider interface; common names |
| TaxaFetch | Occurrence acquisition (GBIF, iNaturalist, DataONE, PDF, literature) and source combination |
| TaxaHabitat | Habitat assignment via LLM; spatial QA/QC |
| TaxaMatch | Sequence and classifier input, BLAST, match standardisation, reference-accession screening |
| TaxaLikely | Match scores into likelihoods (hierarchical Bayesian); reference-coverage auditing |
| TaxaExpect | Occurrence and habitat data into an expected-occurrence prior (theta) |
| TaxaAssign | Posteriors from likelihood plus prior; consensus over hypotheses |
| TaxaFlag | Flagging anomalous detections; expert review; the post-hoc screen |
| TaxaWizard | Workflow designer; generates `llm_prompts/` and the canonical workflow template |

**Export surface: 224 = 219 functions + 5 data objects**, ratified. Per package:
TaxaTools 57, TaxaFetch 32, TaxaHabitat 15, TaxaMatch 30, TaxaLikely 33, TaxaExpect 17,
TaxaAssign 14, TaxaFlag 17, TaxaWizard 9. The root README's Software Inventory table
states the same numbers and is guarded against the tree by
`TaxaWizard/tests/testthat/test-pack.R`, which checks BOTH the export and test-file
columns.

## Dependency chain

```
TaxaTools -> TaxaFetch -> TaxaHabitat -> TaxaExpect -> TaxaAssign -> TaxaFlag
TaxaMatch -> TaxaLikely -> TaxaAssign -> TaxaFlag
TaxaWizard: no TaxaID dependencies; introspects the installed packages via workflow_registry()
```

## Shared data interface

- Classification paths and rank labels: pipe `|` delimited, aligned positionally.
- `point_id` is an exact lat/lon identifier; `grid_id` is an aggregated cell. `grid_id`
  encodes location ONLY, never habitat.
- Taxonomic backbone ids: 1 Catalogue of Life, 3 ITIS, 4 NCBI, 9 WoRMS, 11 GBIF.

## Generated artefacts, and the rule that governs them

`llm_prompts/` and `inst/TaxaID_Workflow_Template.R` are GENERATED, never hand-edited.
The pack comes from `TaxaWizard::workflow_export_prompts()` reading the INSTALLED
packages, plus each README's Quick Start from the repository root; the template comes
from the builder reading `inst/graph/snippets/`.

**The pack and the root README inventory are regenerated BY THE REVIEWER, as the last
commit on the PR's own branch, after the content commits. Contributors do not regenerate
them on their own branches.** CI's artefacts step compares both against their source and treats a SKIP as a
failure, so an artefact cannot trail a merge: a PR that changes an export, a README or a
snippet must carry its own regenerated pack or it will not pass. Always pass
`placeholder_setup_report = TRUE`, or the committed placeholder is overwritten with the
generating machine's own setup check.

## Working rules

- **Never reinstall a package while any R-family process is alive** (`R`, `Rscript`,
  `rsession`, `radian`, `Rterm`, `blastn`). `load_all`, `test`, `check` and `document`
  are safe beside a live run, and so is regenerating the pack, which only reads the
  library. Gate an install in ONE command that aborts:
  `if pgrep -f '(^|/)(R|Rscript|rsession|radian|Rterm|blastn)( |$)' >/dev/null; then echo ABORT; exit 1; fi; Rscript -e 'install...'`
  A `pgrep ... || echo` line followed by a separate install gates nothing.
- Work on a branch; merge only when the maintainer says so. No new export or new
  argument without the maintainer's explicit yes. New arguments go at the END of the
  formals, so main's ordered names stay an exact prefix of the branch's.
- No dated, "Session N", "previously", "no longer" or "legacy" text in roxygen, README,
  vignettes or NEWS. This file, `ecosystem_docs/` and `inst/*_review_response.md` may
  carry history.
- Decisions must be learned from the data; no rule hardcoded for a particular marker.
- Minimise errors over species counts.
- Check `git status` before `git add` in a shared repository, and never use bare
  `git stash` -- the stack is shared across worktrees.
- Run `devtools::document()` after a roxygen change and `devtools::check()` after any
  substantive edit. Ask before changing many existing files at once, or before deleting.
- After completing a task, play a completion sound:
  `afplay /System/Library/Sounds/Glass.aiff`

## Coding conventions

- Native pipe `|>`, never `%>%`. `utils::globalVariables()` first line of any file using
  NSE column names. Internal helpers take a `.` prefix and `@noRd`.
- `dplyr::if_else()`, not `ifelse()`, wherever either branch could be length 1:
  `ifelse()` returns the length of its TEST, so a length-1 branch silently collapses the
  result to one row.
- `%||%` is exported by TaxaTools; never redefine it downstream.
- `package::function()` for cross-package calls.

## Footguns that have actually cost time

- **A roxygen block is stolen by anything between it and its function.** A helper or a
  second function placed there takes the block -- this has shipped an exported function
  UNEXPORTED. Verify with `"fn" %in% getNamespaceExports("Pkg")` after installing.
- **`sprintf()` does not concatenate its arguments.** Splitting a long format string
  across two arguments yields `invalid format` or a silently wrong message. This is the
  most common way a line-length tidy-up introduces a real bug.
- **A bare `Rscript` outside the project root does not pick up `R_LIBS_USER`**, so
  `devtools::install()` can land in the system library without erroring. Run
  `.libPaths(c(path.expand(Sys.getenv("R_LIBS_USER")), .libPaths()))` first and verify
  with `dirname(find.package("<pkg>"))`.
- **A cache guarded by `file.exists()` alone serves stale results.** A cache key must
  encode the question asked, not just the file's presence, and an exclusion keyed on a
  LINE NUMBER stops matching as soon as the file is edited.
- **An empty result is not an answer.** A query that returns nothing reads downstream as
  "this taxon has no data" rather than "this query was malformed"; a success line printed
  under a failing call reads as success. Check the thing, not a proxy for it.
- **A change to an outbound request needs one REAL call before it ships.** A new request
  field passed every mocked test and every offline probe here, and the live model
  rejected it with HTTP 400. Verifying that a value REACHES the provider is not
  verifying the provider accepts it.
- **Zero and absent are different.** A rule that fired on nothing must say 0, not be
  omitted, or "did not fire" and "was not evaluated" become indistinguishable.
