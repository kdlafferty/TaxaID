# Response to the WERC software-release review of TaxaID

This is the repository's response to the release review recorded in
`WERCReview.docx`, whose requests are tabulated in this folder's `README.md`.
Each request is answered below with what the repository now does. It is a
record for the release, kept outside every package; it does not ship in any
built package.

## On deleting test files

The nine packages carry 174 test files (roughly 8,000 tests), run with
`devtools::test()` and by `R CMD check`. They are how several real defects were
caught during pre-publication review, and a standard R package ships its
`tests/` directory so that `R CMD check` can exercise it on any machine. We
read the request as aimed at scratch and development scripts rather than the
test suite; those scripts have been moved out of the repository. We would like
to confirm that reading with the reviewer before deleting anything under
`tests/`.

## Release form

All nine packages are at `Version: 0.1.0` in this tree and are bumped to
`1.0.0` at the release tag. Licensing is CC0 throughout; `code.json` and the
DISCLAIMER state the release type.
